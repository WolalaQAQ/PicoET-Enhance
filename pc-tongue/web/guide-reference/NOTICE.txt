Rendered from the original mesh, morphs and color/normal maps with the original corrective-shape rules.
The Blender material translation and lighting differ from the Unity scene. Front views are mirrored; side views are not.
Tongue poses add skin binding and continuous post-skinning controls to the original tongue mesh.
Independent lip shifts use the original mouth-shift deltas, masked onto the corresponding outer lip.
These added guide controls are not original Meta tongue or independent-lip morphs. Source vertices and existing morph coordinates are unchanged.
The pack contains only rendered images and notices, not FBX models, Blender scenes, SDK code or training labels.
